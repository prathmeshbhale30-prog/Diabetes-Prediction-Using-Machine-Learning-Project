# Diabetes-Prediction-Using-Machine-Learning-Project
Domain: Healthcare Analytics | Data Science | Machine Learning
Developed a machine learning-based predictive model to identify the likelihood of diabetes using patient health data. Performed data preprocessing, Exploratory Data Analysis (EDA), outlier treatment, and feature analysis to improve data quality. Implemented and optimized Decision Tree and Random Forest classifiers using GridSearchCV for hyperparameter tuning and model evaluation. 
Technologies: Python, Pandas, NumPy, Scikit-learn 
Tools: Spyder, Anaconda 
Techniques: EDA, Data Preprocessing, Winsorization, Decision Tree, Random Forest, GridSearchCV
